Install from this Pages site

Enable GitHub Pages

  1. Open your GitHub repository and go to Settings → Pages.
  2. Under Build and deployment, select Deploy from a branch.
  3. Select branch main and folder /(root), then save.
  4. Wait for GitHub Pages to publish, open the public Pages URL, then copy the repository URL shown above.

GitHub Pages changes where these files are served; it does not by itself fix plugin runtime/API errors. V4 also updates the runtime lookup and settings export for better compatibility.

Local display rendering only. Unicode styles are approximations, do not unlock Nitro, and do not change your account's public name. No network calls or token reads are made by the plugin code.
